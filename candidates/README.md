# Candidates

Skills that are written and not yet measured.

They live here rather than in `skills/` because the fourth rule of this
repository says a skill ships with a baseline, and these have none. Publishing
them beside measured skills would make the standard untrue.

Use them if you like. Weigh them as argument, not evidence.
